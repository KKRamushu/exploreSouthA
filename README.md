# ExploreSouthA

A responsive single-page travel agency website built with plain HTML5 and CSS3.

## Features

- Working section navigation
- Responsive layout
- CSS variables
- Global `box-sizing: border-box`
- CSS Grid for tour packages and content sections
- Flexbox for navigation, actions and statistics
- Responsive breakpoints for phone, tablet and desktop
- Custom trip-planning form
- External link and `mailto:` link

## Files

- `index.html` — page structure and content
- `styles.css` — all styling and responsive rules
- hero_background.avif
- kruger.avif
- garden_route.jpg
- cape_town_escape.avif

## Run locally

Open `index.html` in a browser, or use a local development server such as VS Code Live Server.
